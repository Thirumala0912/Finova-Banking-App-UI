# Finova – Smart Banking & Finance App UI

## Project Overview

Finova is a modern banking and finance mobile application UI/UX project designed using Figma. The application focuses on smart banking workflows, digital payments, expense analytics, and modern fintech user experience with interactive prototype navigation.
